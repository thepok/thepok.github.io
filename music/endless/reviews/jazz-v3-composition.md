# V3 composition review — final matched-set follow-up (round6)

## Verdict

**The current candidate has materially stronger musical continuity than the deployed arrangement. No remaining composition blocker was found in the twelve matched pieces reviewed.** This supports proceeding to the separate audio, default-Hero-tone, browser and release checks. It does not demonstrate that the music is professionally equivalent or that the listener will now be fascinated: that requires actual comparative listening and the user's response.

The review covered deployed bank indices0,1,2,3,4,6,10,13,17,23,40,47 across five feels. It compared actual charts, source/response note records and compiled sax/bass events. It did not merely count new plan labels. Detailed negative findings and subsequent requests remain in `composition-round1.md` and `composition-round2.md`.

## What is substantively better

- **Short solos now develop something.** An eight- or four-bar solo contains a remembered statement and a consequence; it no longer waits for a second solo section that often never occurs. The action/source records contain the notes actually used, rather than an inert `development` field.
- **Question/answer has an actual dependency.** The piano response receives the sax question. Bank6, *Leroy Snowfall*, now has four bars of question at1:30.6–1:35.1 and four of response at1:35.1–1:39.6, instead of the accidental four-plus-twelve arrangement. This is a correction to an authored exchange, not just a tidier count.
- **Solo harmony has a destination.** Short routes connect opening A material, contrasting B/C material and the native cadence. Longer concepts distribute a coherent native chorus between voices. The old two-A1-prefix loop no longer defines every short solo. Pacing is edited rather than extended uniformly: several overlong pieces shorten while a few fuller arrangements have more room.
- **The native shape now matters.** For example, the AABA head in bank4 rises toward B and relaxes into A3; the ABAC head in bank0 builds toward C. The old universal four-step head ladder is gone. This still uses section summaries rather than a fully articulated phrase-level global drama, but it is a real connection to the composition's intended shape.
- **Identity and recent conversation are separate memories.** Inspired by the orchestral Kernel architecture, the original theme cell remains immutable for later recall, while immediate responses use the latest actual utterance. This avoids progressively mistaking a cadence fragment for the identity of the song.
- **Recognition and closure can coexist.** Ballad returns keep the opening A hook but take their ending from the actual final cadence. Bank10's return at2:44.8–3:13.4 now resolves through its selected ending harmony to G-flat major9 instead of restoring A1's E-flat13 turnaround and cutting straight to the last chord. Equivalent repairs are present in banks0/13/17.

## Regressions the loop caught and fixed

1. Round1 stored a complete long departure as a phrase and squeezed it into a short reply. Bank47 produced431compiled sax notes with minimum onset interval0.00315seconds; bank2 had a similarly overpacked bass reply. The final version stores a bounded recent cell and never accelerates it merely to fit. Bank47's final planned sax solo is56notes. None of the inspected final sax/bass improvisation passages has the former sub0.08second onset-rate regression.
2. Bounded memory initially compounded `space` dilation until rhythmic identity eroded. Bank10's piano solo had become six mostly held notes, with5.0625-beat durations resulting from repeated1.5× operations. The final version avoids compounding already spacious material and recalls the immutable theme. Bank10's response/recall now retains its recognizable short-short-long-short rhythm, with selective changes in the later phrase. This is an identity repair, not an instruction that sparse passages must contain more notes.
3. Nearest-chord fitting initially flattened a stepwise kernel. In bank6, source65,64,65,64 had become a repeated65. The final response allows chord-scale inner tones and makes the cadence settle; the actual sax line is now65,67,65 and its repetition, while the piano answers with77,74,77. There is audible contour information to recognize rather than only a label claiming development.
4. The first candidate's literal ballad A return discarded the original closing cadence. The final version retains the recognizable first half and restores the intended ending melody/harmony within the same duration.

## What should remain modest in the claims

The statement→consequence→recall/departure grammar is still a finite, fairly recognizable design. Native levels are used chiefly per section; an ensemble-wide phrase-by-phrase build to a uniquely earned moment remains a richer future objective. A response can now be causally connected without necessarily being an inspired response. The single-note piano reply in bank6 is not automatically a defect: its effectiveness depends on listening to the surrounding space and accompaniment, not a minimum-note threshold.

The useful next listening comparison is whole matched pieces, especially bank3 (compact bossa form), bank6 (waltz exchange and contour), bank10 (ballad identity/closure) and bank47 (longer solo memory), with the **same default Hero sound**. Ask whether the theme remains identifiable, whether the handover sounds like a consequence, where the strongest moment is, and whether the return feels earned. Avoid selecting only a few impressive seconds or claiming mastery from these note checks.
